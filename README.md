# WELCOME SC GOOGLE DORK

Google Dork tool sederhana untuk mencari informasi melalui dork, menyimpan hasil, dan installer tools security.

---

## 📌 INFO

Script ini memiliki fitur:

✔ Google Dork Custom (link hasil max 20)  
✔ Google Dork SQLMAP  
✔ Google Dork XSS  
✔ Installer tools:

- sqlmap  
- nikto  
- nmap  
- dalfox  
- paramspider

✔ Hasil disimpan di folder **G-DORK**  
✔ Tampil di terminal  
✔ Warna & menu interaktif  
✔ Detect OS (Linux/Kali → apt, selain itu GitHub clone)

---

## ⚙ INSTALL

1. Install dependensi
```bash
pip install -r text.txt
```
2. Jalankan script
```bash
python G-DORK.py
```
